# House Price Prediction using Simple Linear Regression

## 📌 Project Overview

This project demonstrates the fundamentals of Python data analysis and machine learning using NumPy, Pandas, Matplotlib, and Scikit-learn.

The main machine learning task is to predict house prices based on their area using **Simple Linear Regression**.

The notebook also covers NumPy arrays, multidimensional arrays, array indexing, and slicing basics, providing an introduction to numerical computing in Python.

## 🎯 Problem Statement

House prices often vary according to the size of a property. Estimating the price based on the area can help demonstrate how a machine learning model learns relationships between input features and a target variable.

The objective of this project is to train a Linear Regression model that predicts a house's price using its area.

## 📊 Dataset Information

The project uses the `homeprices_SLR.csv` dataset.

The dataset contains two columns:

| Feature | Description |
|---|---|
| `area` | Area of the house |
| `price` | House price and target variable |

The notebook contains five observations with the following values:

| Area | Price |
|---:|---:|
| 2600 | 550000 |
| 3000 | 565000 |
| 3200 | 610000 |
| 3600 | 680000 |
| 4000 | 725000 |

The `area` column is used as the input feature (`X`), while the `price` column is used as the target variable (`y`).

## 🧠 Model Used: Simple Linear Regression

The project uses the `LinearRegression` model from `sklearn.linear_model`.

Simple Linear Regression learns a linear relationship between a single input feature and a continuous target value.

### How the Model Works

1. The model receives house area as its input feature.
2. Pandas loads the dataset and separates the `area` and `price` columns.
3. Matplotlib is used to visualize the relationship between house area and price.
4. Scikit-learn initializes a `LinearRegression` model.
5. The `fit()` method trains the model using the available area and price observations.
6. The model learns the slope and intercept of the best-fitting regression line.
7. The slope represents the estimated change in price for each additional unit of area.
8. The intercept represents the model's estimated price when the area is zero.
9. The `predict()` method uses the learned relationship to estimate prices for new area values.
10. The model can predict prices for areas such as 1,700, 3,000, and 7,000.

### Linear Regression Equation

The model follows the equation:

**Price = m × Area + c**

Where:

- `Price` is the predicted house price.
- `Area` is the input feature.
- `m` is the learned coefficient or slope.
- `c` is the learned intercept.

## 📈 Model Results

The notebook reports the following learned coefficient and predictions:

| Output | Reported Value |
|---|---:|
| Regression coefficient | 135.7877 |
| Predicted price for area 1,700 | 411,455.48 |
| Predicted price for area 3,000 | 587,979.45 |
| Predicted price for area 7,000 | 1,131,130.14 |

The coefficient indicates that the model estimates an increase of approximately 135.79 price units for every one-unit increase in area.

These predictions are generated by the trained model using the five observations in the dataset. Predictions for areas outside the observed range are extrapolations and may be unreliable.
